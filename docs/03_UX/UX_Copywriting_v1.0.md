# 1. Document Purpose

This document defines all user-facing text used throughout MistyPay MVP.

Objectives:

- Standardize product language
- Improve user experience
- Maintain brand consistency
- Reduce user confusion
- Support localization in future versions

---

# 2. Copywriting Principles

## Principle 1 - Simple

Use:

```text
Payment Successful
```

Avoid:

```text
Transaction Completed Successfully
```

---

## Principle 2 - Human Friendly

Use:

```text
Something went wrong.
Please try again.
```

Avoid:

```text
Unexpected Exception Occurred
```

---

## Principle 3 - Trust Building

Use:

```text
Your payment is being processed.
```

Avoid:

```text
Waiting for blockchain confirmation.
```

---

## Principle 4 - Minimize Crypto Terminology

Avoid:

```text
Wallet Address
Gas Fee
Blockchain Hash
RPC
TRC20 Confirmation
```

except in Transaction Details.

# 21. Transaction Status Mapping

| Internal Status   | User Display              |
| ----------------- | ------------------------- |
| WAITING_USDT      | Waiting for payment       |
| USDT_DETECTED     | Payment detected          |
| USDT_CONFIRMED    | Payment confirmed         |
| PAYOUT_PENDING    | Preparing payout          |
| PAYOUT_PROCESSING | Sending money to merchant |
| SUCCESS           | Payment successful        |
| PAYOUT_FAILED     | Under review              |
| MANUAL_REVIEW     | Under review              |
| REFUND_REQUIRED   | Refund required           |
| FAILED            | Payment failed            |
| EXPIRED           | Payment expired           |

```text

```

## Product Positioning

MistyPay should feel like:

```text
A travel payment app
```

not:

```text
A crypto wallet
```

---

## Primary User Emotion

Users should feel:

```text
Safe
Simple
Fast
Reliable
```

through every screen and interaction.
