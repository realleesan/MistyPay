# 1. Document Purpose

This document defines the strategic roadmap of MistyPay.

Objectives:

- Define product development phases
- Define MVP scope
- Define launch milestones
- Define future expansion plans
- Align product, technology, and business goals

---

# 2. Product Vision

## Vision Statement

```text
Enable foreign travelers to pay Vietnamese merchants
using USDT as easily as local QR payments.
```

---

## Long-Term Goal

```text
Become the preferred travel payment bridge
between cryptocurrency users and local QR payment systems.
```

---

# 18. MVP Definition

MVP is complete when:

```text
User can login

User can scan VietQR

User can enter amount

System generates quote

User confirms payment

USDT detected

VND payout executed

Transaction marked successful

History visible
```

---

# 19. Non-Goals

The following are intentionally excluded from MVP:

```text
Exchange Services

Cash Withdrawals

Peer-to-Peer Transfers

Merchant Lending

Investment Products

Multi-Currency Wallet
```
